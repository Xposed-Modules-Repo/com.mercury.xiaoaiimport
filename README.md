# 小爱课程表导入
![xiaoai](https://raw.githubusercontent.com/Xposed-Modules-Repo/com.mercury.xiaoaiimport/master/img/xiaoai.png)

恢复小爱课程表的导入功能，可选择AI解析/适配仓库/其他课表软件等导入至小爱课程表  

## 作用域
超级小爱(com.miui.voiceassist)

## 下载

RELEASE  

## 使用
**启用模块后正常点击导入-选择适配器进行导入**
